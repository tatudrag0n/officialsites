Mifron Minecraft / プレイガイド

チュートリアル

接続から最初の1日までを解説します。詳細な仕様はゲーム内の案内とDiscordで確認できます。

プロジェクトページへ戻る

STEP 1

接続する

Java / Bedrockとも同じアドレスです。Bedrock版のみポートの指定が必要です。

Java Edition

アドレスを入力

マルチプレイ → サーバー追加で play.mct-official.com を入力します。

Bedrock Edition

ポートを指定

アドレスは同じ、ポートは 19132 です。Geyser経由で参加できます。

認証

6桁コードを送信

初回接続時のキック画面に6桁コードが表示されます。Discordの認証チャンネルへ数字だけ送信し、もう一度接続してください。

Discordが必要です

参加認証、イベント告知、提案と投票、運営からの連絡はDiscordで行われます。まずはDiscordに参加してください。

STEP 2

チュートリアルと配布アイテム

初参加は体験チュートリアルワールドへ案内されます。配布されるアイテムは「メニュー」1個だけです。

チュートリアル

最初の案内

接続すると自動でチュートリアルワールドへ案内され、基本操作をステージ形式で学べます。あとから /tutorial restart で再挑戦、/tutorial skip でスキップできます。

メニュー

すべての入口

配布アイテムを右クリックすると項目が目の前に扇状に展開されます。左クリックで選択し、20秒または離れると自動で消えます。なくした場合は再接続で再配布されます。

ウォレット

MP残高の確認

メニューの「ウォレット」で残高を確認できます。送金は /mf pay <プレイヤー> <金額> です。

ジョブ

職を選ぶ

メニューの「ジョブ」から7職+無職を選べます。最初は無職なので、遊び方に合わせて選びましょう。

目標

はじめてのチェックリスト

チュートリアル卒業後、メニューの「目標」に6項目のチェックリストが表示されます。各項目を達成すると300MPを受け取れます。

紹介

友達を招待する

/mf refer で6桁コードを発行(48時間有効)。参加7日以内の新規プレイヤーが入力すると、お互いのチュートリアル卒業時に3,000MPずつ獲得できます。

ログボ

連続ログインと復帰

連続ログインの節目（7日/30日/100日）で2,000 / 10,000 / 30,000MP、14日以上空けて復帰すると3,000MPを受け取れます。状況はメニューの「ログボ」で確認できます。

経済

MPを増やす・守る

MPはゲーム内通貨です。現実の金銭とは交換できません。

稼ぐ

主な収入源

討伐、進捗達成、クエスト、ジョブ、ログイン・滞在報酬、ショップや商人との取引、紹介などでMPを得られます。

使う

主な支出先

SHOP、棚ショップ、樽ショップ、ファストトラベル、高度な金床、プレイヤー間の取引など。商人は買い取りも行います。

守る

死亡のペナルティ

死亡すると所持MPの50%を失います（端数切り捨て）。高額の取引や購入の前は残高に注意してください。

上限

残高の範囲

所持MPは0〜20億の範囲に制限されます。送金は自分宛てや残高不足の場合に拒否されます。

エメラルドについて

通常のエメラルドを入手してもMPは増えません。MPの増減は必ずシステム経由で行われます。

ワールド

世界ごとのルール

移動は /travel <hub|survival>。通常は500MP・クールダウン60分、冒険者ジョブなら無料・10分です。持ち物はSurvival系と通常系で分かれ、装備・オフハンド・経験値・満腹度も別管理です。

Survival

生活ワールド

拠点（hub）のある生活ワールド。TNTと溶岩は設置・使用できません。ショップ化されたブロックと承認済みの建築は壊せません。月次の自然再生成の対象で、除外リストや保護対象・プレイヤー滞在中のチャンクはスキップされます。

Tutorial

体験チュートリアル

ステージ形式のチュートリアルワールド。滞在中は /travel で移動できません。

特別ワールド

進捗で解放

バベル、ギンヌンガガプ、アガルタ、エリシオン、国家などのワールドは進捗達成で解放され、スペシャルクエストの判定に使われます。

コマンド

覚えるのはこれだけ

メインコマンドは /mifron（省略形 /mf）です。

経済

残高と送金

/mf balance 残高確認
/mf pay <プレイヤー> <金額> 送金

移動

ファストトラベル

/travel <hub|survival> 移動（通常500MP / 冒険者は無料）
/mf list ワールド一覧

ジョブ

職の確認と変更

/mf job 現在のジョブを確認
/mf job <職名> の2段階確定で変更

取引

安全取引

/trade <プレイヤー> 申込
/trade accept 承諾してUIを開く

保護

チャンク保護

/mf protect chunk 保護を提案

その他

チュートリアル・紹介

/tutorial チュートリアルを再開
/mf refer 紹介コードを発行

個人チャットコマンドは使えません

/tell、/msg、/mail、/r などの個人宛メッセージは使えません。1対1の会話はDiscordのボイスチャットやダイレクトメッセージをご利用ください。

ヒント

最初の1日を快適に

まず

やること

1. Discord参加と認証
2. チュートリアルを完了
3. メニューからジョブを選ぶ
4. /travel survival で生活を始める
5. クエストで今日の目標を確認

困ったら

トラブル対処

接続できない場合はDiscordでサーバー状況を確認してください。ワールド移動は /travel が確実です。コマンドは大文字小文字に注意。

ルール

守ってほしいこと

反復狩りやAFK放置は報酬の対象になりません。他人の建築やショップを壊さない。バグは提案ページから報告してください。

質問

サポート

わからないことはDiscordのサポートチャンネルへ。バグ報告と改善提案はサイトの提案フォームから受け付けています。
