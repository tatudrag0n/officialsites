Mifron Guide

チュートリアル

Mifronの世界へようこそ！ここでは基本的な操作方法を解説します。

はじめに 基本操作 コマンド ワールド システム ティップス
📖

はじめに

Mifronは、Minecraft Java EditionとBedrock Editionに対応したサーバーです。Geyserを使用してBedrock Editionのプレイヤーも参加できます。

🎮 サーバーに接続する

  • Java Edition: play.mct-official.com
  • Bedrock Edition: play.mct-official.com (ポート: 19132)

初回接続時は、Discord認証が必要です。Discordに参加して認証を完了させてください。

📋 必要なもの

  • Minecraft (Java Edition 1.20.1以上 or Bedrock Edition)
  • Discordアカウント
  • インターネット接続
🎯

基本操作

🗺️ 移動

  • W: 前進
  • A: 左
  • S: 後退
  • D: 右
  • Space: ジャンプ
  • Shift: しゃがむ/降りる
  • マウス: 視点移動

⚒️ アイテム操作

  • 左クリック: 破壊/攻撃
  • 右クリック: 配置/使用
  • 数字キー (1-9): ホットバーのアイテムを選択
  • E: インベントリを開く
  • Q: アイテムを捨てる
  • F5: 三人称視点

🔍 テレポート

テレポーターを使用すると、エンドポータルフレームにテレポートできます。

  1. テレポーターアイテムを手に持つ
  2. エンドポータルフレームを右クリック
  3. テレポート先を選択

⚠️ テレポートにはMPが必要な場合があります。

⌨️

コマンド

💬 チャットコマンド

Mifronでは、個人チャットコマンド (/tell, /msg など) は使用できません。DiscordのVCを使用してください。

/mf

Mifronのメインコマンド

  • /mf balance - MP残高を確認
  • /mf pay <player> <amount> - MPを送金
  • /mf build enter - Buildワールドに入る
  • /mf build exit - Buildワールドから出る

/merchant

商人を操作

  • /mf merchant spawn - 商人を召喚
  • /mf merchant reroll - 商人のアイテムをリロール
  • /mf merchant clear - 商人を消去

/friend

フレンドを管理

  • /friend add <player> - フレンドリクエストを送る
  • /friend accept <player> - フレンドリクエストを承認
  • /friend remove <player> - フレンドを削除

/quest

クエストを管理

  • /mf quest progress - 進捗を確認
  • /mf quest propose - クエストを提案
  • /mf quest cancel - クエストをキャンセル

/shelfshop

棚ショップを操作

  • /mf shelfshop create - 棚ショップを作成
  • /mf shelfshop remove - 棚ショップを削除
  • /mf shelfshop list - 棚ショップ一覧

/regen

ワールド再生成を管理

  • /mf regen allow <radius> - 再生成を許可
  • /mf regen deny <radius> - 再生成を拒否
  • /mf regen list - 再生成状態を確認
🌍

ワールド

🏠 Hub (メインワールド)

スポーン地点のワールドです。ここから他のワールドへ移動できます。

  • テレポーターで各ワールドに移動
  • ショップ、FFA、ミニゲームなどの施設あり
  • PvPは無効

⛏️ Survival

サバイバルモードのワールドです。

  • リスポーン地点: 0, 101, 0
  • TNTと溶岩は無効
  • 自然再生成は除外制 (月一更新)
  • 棚ショップを作成可能

🎨 Creative

クリエイティブモードのワールドです。

  • スーパーフラットワールド
  • WorldEdit使用可能 (制限あり)
  • 共有ワールド (全プレイヤーが使用)
  • Buildワールドから移行

⚔️ FFA

PvP専用のワールドです。

  • 18種類のキットが利用可能
  • 死亡時にMPの50%を失う
  • キル報酬あり
  • 特別なルールあり

🏃 Athletic

アスレチック (パークール) ワールドです。

  • クリエイティブ、自動ベスト、歴代1位、月間ランキング
  • 報酬: MP
  • コースは定期的に更新

🎮 Minigame

ミニゲームワールドです。

  • 様々なミニゲームが用意されています
  • 報酬: MP
  • 友達と一緒に楽しめます
⚙️

システム

💰 経済システム (MP)

Mifronのメイン通貨です。

  • クエスト、モブ退治、ショップなどで獲得
  • 死亡時に50%を失う (FFAでは100%)
  • /mf balance で残高確認
  • /mf pay <player> <amount> で送金

🛒 ショップシステム

様々なショップが用意されています。

  • 商人: ランダムなアイテムを買取
  • バレルショップ: 商品を陳列して販売
  • ONLINE SHOP: 特殊アイテムを販売
  • 購入樽・買取樽も利用可能

📜 クエストシステム

様々なクエストに挑戦できます。

  • デイリー: 毎日リセット
  • ウィークリー: 毎週リセット
  • 単発: 1回限り
  • 隠し: 特定条件で解放

報酬: MP、アイテム、称号など

🏆 FFAシステム

PvP専用のシステムです。

  • 18種類のキット
  • キットは定期的に更新
  • キル報酬あり
  • 死亡時にMPの50%を失う

📦 インベントリシステム

Survivalワールドのインベントリは他のワールドでも使用できます。

  • 共有インベントリ
  • ワールド間でアイテムを持ち運び可能
  • 一部のワールドでは個別インベントリ

🔄 再生成システム

ワールドの再生成を管理します。

  • 除外制 (デフォルト: 許可)
  • 月一更新
  • 特定のチャンクのみ再生成
  • /mf regen コマンドで管理
💡

ティップス

📌 最初にすること

  1. Discordに参加する
  2. サーバーに接続する
  3. Discord認証を完了する
  4. チュートリアルを読む (今ここで読んでいます！)
  5. Hubで周りを確認する

🎯 MPを稼ぐ方法

  • クエストをクリアする
  • モブを倒す
  • FFAでキルを取る
  • アスレチックでタイムを競う
  • ショップでアイテムを販売する
  • 商人にアイテムを売る

⚠️ 注意事項

  • 個人チャットコマンド (/tell, /msg) は使用できません
  • Survivalワールド外ではモブはスポーンしません
  • TNTと溶岩はSurvivalワールドで無効です
  • WorldEditは制限されています
  • BANされた場合、ロールバックが行われます

🔧 トラブルシューティング

  • 接続できない: サーバーが停止している可能性があります。Discordで確認してください。
  • コマンドが動かない: コマンドのスペルを確認してください。大文字小文字に注意。
  • アイテムが消えた: 死亡時はMPの50%を失います。FFAでは100%を失います。
  • テレポートできない: テレポート先が許可されていない可能性があります。

📞 サポート

何か困ったことがあれば、Discordのサポートチャンネルで質問してください。

バグを発見した場合は、提案システムで報告してください。
