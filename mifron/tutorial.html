プレイガイド

チュートリアル

接続から最初の1日までを解説します。詳細な仕様はゲーム内の案内とDiscordで確認できます。

STEP 1

接続する

Java / Bedrockとも同じアドレスです。Bedrock版のみポートの指定が必要です。

Java Edition

アドレスを入力

マルチプレイ → サーバー追加で play.mct-official.com を入力します。

Bedrock Edition

ポートを指定

アドレスは同じ、ポートは 19132 です。Geyser経由で参加できます。

認証

6桁コードを送信

初回接続時のキック画面に6桁コードが表示されます。Discordの認証チャンネルへ数字だけ送信し、もう一度接続してください。

Discordが必要です

参加認証、イベント告知、提案と投票、運営からの連絡はDiscordで行われます。まずはDiscordに参加してください。

STEP 2

初期アイテムを使いこなす

参加時に自動で配布されます。なくしても再接続で再配布されます。

ウォレット

財布代わり

左クリックでMP残高を確認。棚ショップ・スロット・オークションでは持って右クリックで使います。収納には使えません。

ステータス

自分の記録

右クリックでステータスUIを開きます。進捗、転生、称号、討伐数を確認できます。

テレポーター

移動の主役

右クリックで移動先が目の前に表示され、アイテムを左クリックすると移動します。エンドポータルフレームに使用すると登録地点へ移動。通常のコンパス操作はキャンセルされます。

クエスト本

目標の確認

右クリックでクエスト一覧を開きます。デイリー・ウィークリーの進捗もここから確認できます。

OnlineShop

カタログ購入

右クリックで商品一覧を開きます。Survivalワールドでのみ使用できます。

注意

専用アイテムは売れない

Mifronの専用アイテムとショップワンドは、棚ショップで売却できません。

経済

MPを増やす・守る

MPはゲーム内通貨です。現実の金銭とは交換できません。

稼ぐ

主な収入源

討伐、進捗達成、クエスト、アスレ、ミニゲーム、ログインと滞在報酬、ショップでの取引などでMPを得られます。

使う

主な支出先

OnlineShop、樽ショップ、オークション、スロット、ミニゲームの解放への納品など。商人は買い取りも行います。

守る

死亡のペナルティ

FFA以外で死亡すると所持MPの50%を失います（端数切り捨て）。高額の取引や出品の前は残高に注意してください。

上限

残高の範囲

所持MPは0〜20億の範囲に制限されます。送金は自分宛てや残高不足の場合に拒否されます。

エメラルドについて

通常のエメラルドを入手してもMPは増えません。MPの増減は必ずシステム経由で行われます。

ワールド

世界ごとのルール

持ち物はSurvival系と通常系で分かれます。装備・オフハンド・経験値・満腹度も別管理です。

Hub

ロビー

拠点。テレポーターから各ワールドへ移動します。

Survival

生活ワールド

TNTと溶岩は設置・使用できません。ショップ化されたブロックと承認済みの建築は壊せません。自然再生成は許可リストのチャンクのみ対象です。

Creative

建築ワールド

プレイヤーごとのフラットワールド。CreativeモードでWorldEditが使えます（巨大な一括編集は制限）。他人のワールドには入れません。

Athletic

固定昼

スタート地点に入ると計測開始。同名のゴールで終了です。クリア・自己ベスト・歴代1位・月間順位にMP報酬があります。

Minigame

固定昼・PvP可

複数のミニゲームを遊べます。PvPが有効なのはMinigameと設定対象のみです。

FFA

対戦ワールド

18キットのPvP。インベントリは保存されません。退出するとFFA前の状態に戻ります。

コマンド

覚えるのはこれだけ

メインコマンドは /mifron（省略形 /mf）です。

経済

残高と送金

/mf balance 残高確認
/mf pay <プレイヤー> <金額> 送金

建築

Creativeへの出入り

/mf build enter 入る
/mf build exit 出る
完成した建築は /mf structure submit <名前> で提出（承認後にSurvivalへ設置可能）

アスレ

ランキング

/mf athletic ranking <コース名> [monthly|alltime] 順位を確認

FFA

参加と戦績

/mf ffa leave 退出
/mf ffa stats 戦績確認

移動

ワールド一覧

/mf list ワールド一覧
/mf tp <ワールド名> 移動

その他

チュートリアル

/tutorial ゲーム内で操作説明を再表示します。

個人チャットコマンドは使えません

/tell、/msg などの個人チャットは制限されています。1対1の会話はDiscordのボイスチャットやダイレクトメッセージをご利用ください。

ヒント

最初の1日を快適に

まず

やること

1. Discord参加と認証
2. テレポーターでSurvivalへ
3. OnlineShopで道具を購入
4. クエスト本で今日の目標を確認

困ったら

トラブル対処

接続できない場合はDiscordでサーバー状況を確認してください。ワールド移動はテレポーターが確実です。コマンドは大文字小文字に注意。

ルール

守ってほしいこと

反復狩りやAFK放置は報酬の対象になりません。他人の建築やショップを壊さない。バグは提案ページから報告してください。

質問

サポート

わからないことはDiscordのサポートチャンネルへ。バグ報告と改善提案はサイトの提案フォームから受け付けています。
