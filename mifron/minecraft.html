Showcase

サーバーの雰囲気

ワールドの空気感を短いループ映像にまとめました。参加する前に、どんな世界かを先に感じ取れます。

参加方法を見る チュートリアルを読む

はじめての方

3ステップで参加

認証とイベントの受付はDiscordで行います。

STEP 1

Discordに参加

招待リンクから参加します。参加認証、イベント告知、提案と投票はすべてDiscordで行われます。

STEP 2

6桁コードで認証

初回接続時のキック画面に6桁コードが表示されます。Discordの認証チャンネルへ数字だけ送信してください。

STEP 3

再接続して遊ぶ

認証完了後、もう一度接続するとそのまま遊べます。初回は体験チュートリアルへ案内され、終了後は /travel で hub・survival・main へ移動できます。

より詳しい操作はチュートリアルにまとめています

アイテムの使い方、ショップ、ジョブ、クエストの消化方法まで、手順付きで説明しています。

ワールド

遊び場を選ぶ

移動は /travel <hub|survival|main> が便利です。通常は500MP・クールダウン60分、冒険者ジョブなら無料・10分になります。接続中のワールド一覧は /mf list で確認できます。

Survival

生活ワールド

メインの生活ワールド。拠点（hub）もここにあります。TNTと溶岩は使えず、SHOPはこのワールド限定です。

main

建築ワールド

岩盤平面のセミクリエイティブ。設置したブロックは承認制で、承認後に固定されます。/mf main submit からschematicの設置申請もできます。

Tutorial

チュートリアル

初参加時に案内される体験ワールド。基本操作をステージ形式で学べます。あとから /tutorial restart で再挑戦できます。

特別ワールド

進捗で解放

バベル、ギンヌンガガプ、アガルタ、エリシオン、国家などのワールドは進捗達成で解放され、スペシャルクエストの判定にも使われます。

持ち物はワールドグループごとに分かれます

Survival系（Survival・Nether・End）と通常系で、インベントリ・装備・経験値・満腹度が別管理です。KeepInventoryは全ワールドで有効、PvPは既定で無効です。

経済

MPでつながる

討伐、進捗、クエスト、ジョブ、ログイン・滞在報酬、取引などで増減します。残高は0〜20億MP、死亡すると所持MPの50%を失います（端数切り捨て）。エメラルドを拾得してもMPにはなりません。

Wallet

ウォレット

配布アイテムの扇状メニューから開けます。専用アイテムとして棚ショップの購入にも使います。

  • メニューの「ウォレット」でMP残高を確認
  • 送金は /mf pay <プレイヤー> <金額>
  • 残高の上限は2,000,000,000MP
Shelf Shop

棚ショップ

棚の3枠に並ぶアイテムは商品の見本です。同じ素材の在庫は全棚で共有され、プレイヤーの売却で増え、購入で減ります。

  • ウォレットを持って右クリック: 在庫とMPを消費して購入
  • 見本と同じアイテムを持って右クリック: 1個売却
  • Mifron専用アイテムとワンドは売却不可
Barrel / Merchant

樽ショップと商人

樽ショップは27商品（先頭3枠が掘り出し物）を並べ、購入した枠だけ新しい商品に入れ替わります。商人はSurvivalの中央広場外に生成され、クリックで1個、Shift+クリックで可能な限り一括取引します。

SHOP

SHOP（Survival限定）

メニューの「SHOP」から開けるカタログ式ショップです。装飾・材料・道具類・食料・その他の5ジャンルから、ページ送りで購入できます。

  • 購入で在庫が減り、売却で増える在庫制
  • 在庫が少ないと高騰、多いと下落（0.25〜4倍）。月初に各商品+5補充
  • 左クリック購入 / 右クリック1個売却 / Shift+右クリック一括売却
Trade

安全取引 (/trade)

プレイヤー同士でアイテムとMPを同時交換できる取引UIです。提示を変えると確定がリセットされる詐欺防止設計で、途中退出時は提示が全額返却されます。

  • /trade <プレイヤー> で申込、相手の /trade accept で開始
  • 双方が確定すると成立。MP上限は100万MP
Travel

ファストトラベル (/travel)

hub・survival・main へすぐ移動できます。通常は500MP・クールダウン60分。冒険者ジョブなら無料になり、クールダウンも10分に短縮されます。

アイテム

配布アイテムはメニューひとつ

参加時に配布されるのは「メニュー」アイテム1個だけ。なくした場合も再接続で再配布されます。右クリックすると項目が目の前に扇状に展開され、左クリックで選べます（20秒または離れると自動で消えます）。

SHOP

カタログ購入

商品一覧を開きます。Survivalワールドでのみ使用できます。

ウォレット

MP残高を確認

メニューから現在のMPを確認できます。

ステータス

自分の記録を見る

進捗、討伐、図鑑、ギア、称号、転生の6タブを確認できます。

クエスト

クエストを確認

クエスト一覧とデイリー・ウィークリーの進捗を確認できます。

ジョブ / ギア

職と装備を選ぶ

ジョブの選択・変更と、解放済みギア（最大3つ）のON/OFFを行います。

取引 / 投票 / ログボ / 目標

その他の項目

取引申込、投票サイト、連続ログイン状況、はじめての目標チェックリストを開けます。

フレンド

申請と一覧

フレンド申請・承認・削除ができます。/friend add|accept|remove でも操作できます。フレンドチャットは廃止され、1対1の会話はDiscordのVC/ダイレクトメッセージを使います。

特殊アイテム

低確率で手に入る特別なアイテム

通常アイテムの取得・クラフト時に、ごく低確率で特殊アイテムへ変化することがあります。売買不可・不可壊で、見た目や行動の幅を広げます。

フックショット

釣り竿 → 引っ掛けて急接近

釣り竿を取得・クラフトした時、0.05%で変化。ウキを引っ掛けた場所へ一気に近づきます。

スクラッチ

紙 → 運試しでMP

紙を取得・クラフトした時、1%で変化。右クリックで削るとMPを獲得でき、低確率で当たりが出ます。

ジェットパック

チェーンのチェストプレート → 空を飛ぶ

チェーンのチェストプレートを取得・クラフトした時、1%で変化。ブレイズパウダンを燃料に空を飛びます。

残響の結晶

残響の欠片 → ソニックビーム

残響の欠片を取得・クラフトした時、2%で変化。ウォーデンのビームを放つ使い捨てアイテムです。

ファイアーボール

ファイアチャージ → 火の玉

ファイアチャージを取得・クラフトした時、0.1%で変化。ガストの火の玉を撃ち出す使い捨てアイテムです。

ローラースケート

鉄のブーツ → 高速滑走

鉄のブーツを取得・クラフトした時、0.01%で変化。走ると氷の上のように滑走します。

帰還チャーム

エンダーパール → スポーンへ帰還

エンダーパールを取得・クラフトした時、0.2%で変化。右クリックでSurvivalスポーンへ戻る使い捨てアイテムです。

治療包帯

糸 → 体力回復

糸を取得・クラフトした時、0.5%で変化。右クリックで体力を回復する使い捨てアイテムです。

朽ちた剣

ネザライトの剣 → 効果準備中

ネザライトの剣を取得・クラフトした時、0.001%で変化。ドロップはしますが、効果はまだ実装されていません。

特殊アイテムも提案できます

新しい効果・抽選率・モチーフのアイデアは提案フォームから受け付けています。審査後に実装し、提案一覧へ状態を反映します。特殊アイテムは売買不可・不可壊です。

クエスト

毎日の目標が報酬になる

全部で46種。デイリーとウィークリーは期間ごとに5件が抽選され、マンスリーは固定表示、スペシャルは条件発生型です。各タイプの「完全達成」を取ると追加報酬があり、反復・AFKの報酬は抑制されます。

Daily

デイリー（毎日5件+職の日課）

採掘、建築、討伐、農業、取引、探索、釣りなどから毎日5件が抽選されます。自分のジョブの日課（J01〜J07）と完全達成も表示され、全達成で追加報酬。

Weekly

ウィークリー（5件+完全達成）

数千ブロックの採掘・建築、討伐遠征、交易、探索など週単位の目標。達成済みの一覧から完全達成へつながります。

Monthly

マンスリー（7件固定）

月間採掘王、月間建築家、月間討伐者など固定表示。報酬は数千MP規模で、全達成で「マンスリー完全達成」を受け取れます。

Special

スペシャル 18種

初ドラゴン討伐、バベル到達、転生など条件発生型の特別クエスト。いちばん高い報酬は20,000MPです。

Event

定期イベント

毎週土曜20:00の「釣り大会」をはじめ、イベント中だけ表示される限定クエストがあります（例: S30「釣り大会 完走」）。開始15分前・開始・終了に全体告知されます。

Bonus

転生ボーナス

全進捗達成後、転生でMP報酬にボーナス倍率が付きます。上限120%、圧縮率25%。

Quest Map

クエストボードを見る

全クエストをキャンバス上で確認できるクエストボードを用意しています。ピンチで拡大、ドラッグで移動。

クエストボードを開く クエスト提案フォームを開く

提案システム

みんなで決める

提案とバグ報告を受け付け、審査後に実装します。実装された提案は、サイトの提案一覧で状態を確認できます。

Feature

機能の提案

新しいワールド、アイテム、玩法などの提案。タイトルと説明を書いて送信します。

Bug

バグ報告

再現手順と発生条件を書いてください。報告は仕様変更より優先して確認します。

Deletion

削除の提案

クエストカードから「この内容で提案する」で削除を提案できます。対象クエストを指定して送信します。

Vote

投票で優先順位

提案とクエストには高評価・低評価が付けられます。運営レビューでは比率で優先度を確認します。

提案一覧を見る 提案を送る クエストを提案

ジョブ

7職から選んで生きる

狩人・農民・鍛冶屋・商人・釣り人・鉱夫・冒険者に無職を加えた単一選択です。/mf job で確認、/mf job <職名> の2段階確定で変更でき、切替クールダウンは24時間。対応した行動の報酬が増え、職ごとの特典が使えます。

狩人討伐

モブ討伐の収入が+20%。Elite討伐ではダイヤが確定ドロップし、討伐証も手に入ります。

農民収穫

作物の収穫でMPを獲得。完熟した作物の収穫では+1個が確定でドロップします。

鍛冶屋エンチャント

高度な金床のMPコストが20%割引。エンチャント上限突破+5と、上限を超えた分のMP倍率半減。

商人取引

売却の収入が+10%。ショップでの購入割引もさらに+10%されます。

釣り人釣り

釣り成功でMPを獲得。宝釣りでエメラルド8%・ダイヤモンド2%の追加チャンスがあります。

鉱夫採掘

採掘でMPを獲得。深層鉱石からの追加ドロップと、溶岩ダメージ半減の特典があります。

冒険者探索

未踏破チャンクの初回訪問でMPを獲得。/travel が無料になり、クールダウンも10分に短縮されます。

無職なし

どの職にも就いていない状態。ボーナスはありませんが、いつでも職を選べます。

ジョブレベルと称号

対応する行動でXPが貯まり、レベルアップすると収入ボーナスが+0.5%/Lv加算されます（上限+25%、最大Lv.50）。Lv.10/25/40で称号「常連」「熟練者」「達人」を解放し、節目レベルは全体告知されます。レベルと称号はステータスUI、変更はメニューの「ジョブ」から確認できます。
