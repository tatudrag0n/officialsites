# MCT 統合公式サイト

Cloudflare Pages の1プロジェクトで公開できます。

## URL構成
- `/` MCT
- `/mifron/` Mifron
- `/crewmate/` CREWMATE
- `/texroot/` TEXROOT

## 公開方法
このフォルダの中身を Cloudflare Pages の **Upload assets** にアップロードしてください。

## Discordリンク
`assets/config.js` の `discord:'#'` を実際の招待URLへ変更してください。

## 主な修正
- MCTロゴの黒背景を除去し、濃色文字の透明PNGへ変換
- 旧ブランド名を公開サイト上で Mifron に統一
- 仕様書・FFA Kits・事業計画書・経済仕様書を再同期
- 白ベース＋角張った独自UIへ再設計
